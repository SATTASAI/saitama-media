GET STARTED

เชื่อมคลังสื่อของคุณ

  1. ตั้งค่า Google OAuth ครั้งแรก

    เจ้าของระบบตั้งค่า Client ID, Client Secret, อีเมลเจ้าของ และคีย์เข้ารหัสใน Cloudflare Workers ตามคู่มือ README ใน GitHub

  2. เข้าสู่ระบบด้วย Google

    ใช้บัญชีเจ้าของคลังที่ตั้งไว้ ระบบเข้าถึงเฉพาะไฟล์และโฟลเดอร์ที่ระบบนี้สร้าง

  3. เพิ่มสื่อและเริ่มจัดระเบียบ

    ตรวจชื่อ วิชา ชั้น และประเภทก่อนอัปโหลด ไฟล์ทั้งหมดจะอยู่ในโฟลเดอร์ “คลังสื่อครู”

เชื่อม Google Drive →
CHATGPT → YOUR LIBRARY

สร้างแล้วส่งเข้าคลัง

ใช้ผ่าน GPT ที่กำหนดค่า Actions ไว้เท่านั้น การสนทนาทั่วไปใน ChatGPT ยังไม่ส่งไฟล์เข้าคลังเอง
  1. เปิดระบบนี้บน Cloudflare Workers (HTTPS)

    เชื่อม Google Drive และตั้ง INGEST_API_KEY ในเซิร์ฟเวอร์ (อย่างน้อย 32 ตัวอักษร)

  2. เพิ่ม Action ใน GPT ของคุณ

    นำเข้าลิงก์ OpenAPI ด้านล่าง แล้วตั้ง Authentication เป็น API Key แบบ Bearer โดยใช้คีย์จากเซิร์ฟเวอร์

  3. สั่งสร้างสื่อพร้อมบันทึก

    GPT ส่งเนื้อหา HTML, Markdown หรือข้อความเข้าคลังได้ ระบบจะตั้งชื่อและจัดหมวดให้ พร้อมคืนลิงก์ Google Drive ส่วนไฟล์ PDF หรือ Office ต้องส่งข้อมูลไฟล์จริงผ่าน API
